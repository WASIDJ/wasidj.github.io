<h2 id="二llm-agent-改变了什么">二、LLM Agent 改变了什么</h2>
<p>2026 年的今天，任何一个 LLM Agent 都可以：</p>
<ul>
<li>在 30 秒内写出一篇完整的 Git 教程</li>
<li>用你从未见过的视角解释 gRPC 的工作原理</li>
<li>生成一份带交互式图表的 Redis 深度指南</li>
</ul>
<p><strong>它唯一不能做的是：替你做出判断。</strong></p>

<p>这并不是说 AI 写的教程没有价值——恰好相反，AI 教程的价值太高了，高到<strong>不值得人类去重复</strong>。</p>
<p>如果你的博客内容是 AI 30 秒就能生成的东西，那你的读者为什么要来看？答案很残酷：<strong>他们不会来</strong>。</p>
<hr>
<h2 id="三新的创作哲学三问筛选法">三、新的创作哲学：三问筛选法</h2>
<p>经过这次清理，我建立了一套博客创作的筛选标准。发表前，问自己三个问题：</p>
<h3 id="第一问这篇文章是否体现了我的判断力">第一问：这篇文章是否体现了我的判断力？</h3>
<p>判断力是 LLM Agent 时代最稀缺的能力。</p>
<ul>
<li>你选择研究什么、忽略什么？</li>
<li>你在两个方案之间如何取舍？</li>
<li>你从某个经历中学到了什么只有你能学到的东西？</li>
</ul>
<p>如果文章可以被一个 prompt 复现，那它不值得发表。</p>
<h3 id="第二问这篇文章是否有从-0-到-1的成分">第二问：这篇文章是否有"从 0 到 1"的成分？</h3>
<p>AI 擅长"从 1 到 100"——把已有知识结构化、完善化、可视化。</p>
<p>人类擅长"从 0 到 1"——从模糊的想法出发，构建一个不完美但真实的 MVP。</p>
<pre class="mermaid-source"><code class="language-mermaid">graph LR

<p><strong>"不完美但原创"远比"完美但重复"有价值。</strong></p>
<h3 id="第三问这篇文章是否诚实地记录了我的生活或思考">第三问：这篇文章是否诚实地记录了我的生活或思考？</h3>
<p>日常生活记录、人生经验总结——这些是 AI 无法伪造的东西。</p>
<ul>
<li>你看了一部 1930 年的电影，有什么感受？</li>
<li>你经历了一次职业选择，背后是什么思考？</li>
<li>你观察到某个社会现象，你的立场是什么？</li>
</ul>
<p>AI 可以生成"西线无战事影评"，但无法生成<strong>你坐在电影院里、在 2026 年、作为你这个人——的真实感受</strong>。</p>
<hr>
<h2 id="四内容分类框架">四、内容分类框架</h2>
<p>基于这个哲学，我把博客内容分为三类：</p>





























<table><thead><tr><th>类型</th><th>定义</th><th>例子</th><th>价值来源</th></tr></thead><tbody><tr><td><strong>思路 → MVP</strong></td><td>从一个伟大的想法出发，完成最小可行验证</td><td>FIDO DIY、Git Worktree 方案</td><td>判断力和执行力</td></tr><tr><td><strong>日常生活</strong></td><td>真实的经历和观察</td><td>观影感受、旅行见闻</td><td>不可复制的体验</td></tr><tr><td><strong>人生经验</strong></td><td>长期积累的思考总结</td><td>工作方法论、认知框架</td><td>时间和实践沉淀</td></tr></tbody></table>
<p>这三类的共同特征是：<strong>都要求创作者的在场</strong>。没有你的判断、你的经历、你的思考，这些内容就不存在。</p>
<hr>
<h2 id="五关于干货的重新定义">五、关于"干货"的重新定义</h2>
<p>传统博客圈喜欢说"干货"——即实用、可操作的内容。</p>
<p>但在 LLM Agent 时代，"干货"的定义需要更新：</p>
<ul>
<li><strong>旧干货</strong>：操作步骤、命令参数、配置方法</li>
<li><strong>新干货</strong>：思考框架、决策依据、经验教训</li>
</ul>
<p>为什么？<strong>因为旧干货正在急剧贬值，新干货正在持续升值。</strong></p>
<pre class="mermaid-source"><code class="language-mermaid">timeline
    title 博客内容价值趋势 (2024-2026)
    2024 : 传统教程价值高峰
         : AI 写代码能力爆发
    2025 : 工具使用指南快速贬值
         : AI 写作能力成熟
    2026 : 纯教程内容几乎归零
         : 判断力/经验类内容价值凸显
</code></pre>
<p>这是否意味着不要写技术内容？不。</p>
<p>这意味着技术内容的写法需要改变：</p>
<pre class="shiki shiki-themes catppuccin-mocha catppuccin-latte" style="background-color:#1e1e2e;--shiki-light-bg:#eff1f5;color:#cdd6f4;--shiki-light:#4c4f69" tabindex="0"><code><span class="line"><span>❌ 旧写法：列出所有 git 命令</span></span>
<span class="line"><span>✅ 新写法：为什么选择这个方案、踩了什么坑、实际效果如何</span></span>
<span class="line"><span></span></span>
<span class="line"><span>❌ 旧写法：翻译协议规范</span></span>
<span class="line"><span>✅ 新写法：密码认证的根本问题是什么、DIY 方案的取舍、对安全的理解</span></span>
<span class="line"><span></span></span></code></pre>
<p><strong>同样的主题，不同的切入角度，产生完全不同价值的内容。</strong></p>
<hr>
<h2 id="六创作即判断">六、创作即判断</h2>
<p>回到最初的问题：在 LLM Agent 时代，博客应该创造什么？</p>
<p>我的答案是：<strong>创造判断。</strong></p>
<p>每一篇博客文章，都应该是一次判断力的公开展示。</p>
<ul>
<li>你判断什么值得关注</li>
<li>你判断什么值得放弃</li>
<li>你判断什么方法有效</li>
<li>你判断什么方向正确</li>
</ul>
<p>AI 可以做很多事情，但它不能替你判断——<strong>因为你才是那个要为判断结果负责的人</strong>。</p>
<p>这就是 LLM Agent 时代，博客创作的意义。</p>
<hr>
